## /rootgraph-conventions $ARGUMENTS

Разбери `$ARGUMENTS` и выбери один из трёх режимов.

### Режим 1 — `--diff`

Аргументы после `--diff` — необязательные номера версий `from` и `to`
(например `--diff 2 4`); без них сравниваются последняя версия и
предыдущая перед ней.

1. Вызови `rootgraph_conventions_diff` с этими `from`/`to` (не передавай
   параметр вовсе, если он не указан явно — сервер сам подставит умолчание).
2. Если конвенции проекта ещё ни разу не сохранялись (инструмент вернёт
   ошибку "не найдены") — сообщи об этом и предложи запустить полный проход
   (`/rootgraph-conventions` без аргументов).
3. Если `changes` пуст — так и скажи: между этими версиями ничего не
   изменилось.
4. Иначе покажи изменения человеку: путь (`sections.C.answers[1].answer`
   и т.п.), было → стало. Переведи путь в понятную формулировку (секция +
   примерный номер вопроса), не показывай сырой JSON-путь как единственное
   объяснение.

### Режим 2 — `--section <ключ>[,<ключ>...]`

Частичный проход только по перечисленным секциям (например
`--section G,H`). Загрузи навык **rootgraph-conventions-wizard** и
проведи по нему пользователя, ограничившись указанными секциями.

### Режим 3 — без аргументов (полный проход)

1. Сначала вызови `rootgraph_conventions_get`, чтобы узнать, что уже
   сохранено (частичный черновик от прошлого раза, если он есть, — не
   спрашивай заново то, что там уже отвечено, если только пользователь сам
   не просит пересмотреть). Отсутствие сохранённой версии — это не ошибка,
   а обычное состояние нового проекта, продолжай как есть.
2. Загрузи навык **rootgraph-conventions-wizard** и проведи пользователя по
   всем секциям 0 и A–I из `docs/conventions-questionnaire.md`, следуя его
   инструкциям (по одной секции за раз, не вываливая все ~70 вопросов
   разом).

### Общее для режимов 2 и 3

- После сохранения каждой секции (`rootgraph_conventions_save`) сервер
  возвращает новую версию, а плагин сам перегенерирует
  `.claude/rootgraph/conventions.md` на диске — Claude не рендерит этот файл
  вручную и не пишет в него напрямую.
- `.claude/rootgraph/conventions.md` — обычный файл репозитория (как
  `.claude/rootgraph/config.json`): он не коммитится этой командой
  автоматически. По завершении прохода скажи пользователю, что файл
  изменился, и спроси, закоммитить ли изменения — коммит без явного
  согласия делать нельзя (см. `SKILL.md` про автономный git этого проекта).
- Если ответ на вопрос раздела G похож на реальный секрет — сохранение
  `rootgraph_conventions_save` вернёт ошибку сканера секретов. Это не сбой,
  которую нужно обойти — попроси пользователя переформулировать ответ без
  самого значения (путь/расположение вместо значения), см. G в
  `docs/conventions-questionnaire.md`.
