## Опросник командных конвенций Rootgraph

Полная версия, секции 0 и A–I. Этот файл лежит рядом с `SKILL.md` навыка
`rootgraph-conventions-wizard` и ставится вместе с плагином — доступен в
любом проекте, а не только в репозитории Rootgraph. Заполняется через
`/rootgraph-conventions`; результат — `.claude/rootgraph/conventions.answers.json`
(сырые ответы) и `.claude/rootgraph/conventions.md` (рендер, коммитится,
читается каждой сессией). Как `SKILL.md` использует этот файл — см. сам
`SKILL.md` рядом; подробности архитектуры — [architecture.md, §13](../../docs/architecture.md).
